**Angler Associate**

A [BlishHUD]([url](https://blishhud.com/)) module for Guild Wars 2 that helps you find fish - what day/night cycle you're in, where to find specific fish (down to the exact map and nearest waypoint), what you can catch at a specific fishing hole, tracking achievement progression and showing Daily.

**Features**

> Day/night clock - display current day/night state for both Tyria/Nayos and Cantha/Castora + how much time's left until the next phase

> Today's daily fisher - shows the current Daily Fisher from the EOD achievement pool. Refreshes correctly on server reset.

> Full fish database - every fish with its rarity, fishing hole, favoured bait, where to find them and at what time of the day. All expansions supported.

> Detailed fish view - click a fish to see every hole it can be caught at, the recommended fishing power for each, and drill into which regions and maps have that hole. Click a location to copy its nearest waypoint to your clipboard - locations without a waypoint (or with a restricted/timegated/otherwise unusual one) get a note explaining why.

> Filter by fishing hole - stuck at a specific hole and want to know what's catchable there? Search and select a hole to filter the whole table down to it. Fish that can be caught anywhere (including Open Water) get pushed to the bottom rather than cluttering the top.

> Region picker - click a region's icon to filter by it (click again to clear). Replaces the old continent/region dropdowns.

> Filter options - region, achievement collection (including Avid collections, once the base one's complete), bait, fishing hole, and available during the current time of the day

> Hide collected - hides fish you've already caught, using your account's achievement progress (requires an API key with account and progression permissions). Shows a proper "fully collected" message instead of an empty table when it hides everything.

> Search box - search for any fish by its name

**Installation**

You can download the module from BlishHud. Otherwise, for manual installation, download the bhm file and copy it to the modules folder (by default it should be ~\Documents\Guild Wars 2\addons\blishhud\modules\

**API Permissions**

> Account - required to authenticate the API key.

> Progression - required to read your fishing achievement/collection progress, used for the "Hide collected" filter.

> No data is sent anywhere outside the standard GW2 API calls made directly to ANet's servers.
